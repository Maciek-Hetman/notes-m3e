# Notes

A simple Android application for taking notes, built with Jetpack Compose and modern Android architecture.

## Features

- **Markdown Support:** Write notes using Markdown with visual transformation, a dedicated Markdown toolbar, and rendered output.
- **Code Syntax Highlighting:** Clear and readable code blocks within your notes.
- **Offline Storage:** All notes are securely saved on your device using a local Room database.
- **App Settings:** Customizable preferences available in a dedicated settings screen.
- **Haptic Feedback:** Interactive elements provide subtle tactile responses.
- **Modern Architecture:** Built following MVVM principles, utilizing Jetpack Compose for the UI, ViewModels, and Repository pattern for data management.
